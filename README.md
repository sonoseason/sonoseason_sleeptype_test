# SONOSEASON Mattress Test V1

모바일 우선으로 만든 무료 정적 웹사이트 프로토타입입니다.

## 실행 방법
index.html을 Chrome/Edge에서 더블클릭하면 실행할 수 있습니다.

## 수정할 파일
- index.html: 화면 구조/문구
- style.css: 디자인
- script.js: 질문/결과/추천 로직

현재는 테스트 기능 확인용 임시 문항과 임시 추천 결과가 들어 있습니다.
실제 제품 정보와 문항은 추후 교체하면 됩니다.

## 무료 배포
GitHub에 세 파일을 업로드한 뒤 Cloudflare Pages에 연결하면 무료로 웹에 공개할 수 있습니다.
